# 30-Days-of-Terraform

Welcome!
This repository is my personal space for the **#30DaysOfTerraform** challenge.  
The goal is to stay consistent, learn Terraform and document every step as I grow through these 30 days.

I’ve paused my AWS blogging series for a bit because I wanted to challenge myself with something structured and this challenge felt like the perfect opportunity. 
Each daily blog will be accompanied by hands-on notes right here in this repo, keeping learning practical and honest.

---

## 📂 Repository Structure

This repository is organized by **30 folders**, one for each day of the challenge:

Day 1/
Day 2/
Day 3/
...
Day 30/

Every folder will include:
-  **Daily learnings**
-  **Code snippets / Terraform configs**
-  **Practice tasks**
-  **Video link for that day**

---

## Why This Challenge?

I’ve always believed that the best way to learn is by *showing up every day*, even if the steps are small.  
This challenge helps me:

- build a habit  
- learn Terraform the right way  
- stay committed through a structured plan  
- share my progress with anyone learning alongside me  

Also, along the way, I’ll be dropping **30 small facts about me** one each day to make this journey a bit more fun and personal.

All the best to me and thank you for being here!
