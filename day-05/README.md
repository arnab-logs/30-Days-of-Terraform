Hello and welcome back to our 30 Days of AWS Terraform journey!

In Day 5, we explored **Terraform variables** and how they help make our infrastructure code cleaner, safer, and easier to maintain. Variables allow us to reuse values across multiple resources, prevent human errors, and simplify switching environments.

Here’s a quick overview of what we covered today:

## Topics Discussed

### 1. Input Variables

* Let you define a value once and use it across multiple resources.
* Example: environment = dev
* Helps avoid repetitive typing and mistakes.
* Changing the value in one place updates all references.

### 2. Local Variables

* Internal helper variables inside the Terraform configuration.
* Can combine or shape values from input variables for convenience.
* Example: `local.bucket_name = "arnab-day-5-${var.environment}"`
* Reduces repetition and makes configuration easier to read and maintain.

### 3. Output Variables

* Show key values generated by Terraform after resource creation.
* Example: `VPC ID`, `EC2 instance ID`
* Acts like a message from Terraform, letting us know exactly what was created.
* Can be accessed using `terraform output`.

### 4. Variable Precedence

* Determines which value Terraform uses when multiple sources provide values.
* Sources (in order of increasing precedence):

  1. Default value in the variable block
  2. Environment variables (`export TF_VAR_environment=stage`)
  3. `.tfvars` files (e.g., `terraform.tfvars`)
  4. Command-line override (`-var` or `-var-file`)
* Ensures flexibility when switching environments or overriding values temporarily.

## Summary

* **Input variables** bring values in from outside.
* **Local variables** allow shaping and reusing values internally.
* **Output variables** give values back after resource creation.
* **Variable precedence** ensures Terraform knows which value to use when multiple sources exist.

Using variables effectively keeps your Terraform code **DRY (Don’t Repeat Yourself)**, consistent, and easier to maintain, especially as projects scale.
